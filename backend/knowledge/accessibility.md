# Accessible website defaults

Use one clear H1 and preserve heading order. Interactive controls need visible focus states, keyboard operation, and descriptive labels. Color contrast should meet WCAG AA. Do not communicate status using color alone. Images need useful alternative text unless decorative. Respect reduced motion preferences and avoid surprise movement.

Buttons describe actions while links describe destinations. Forms pair every field with a label, explain validation near the field, and keep error summaries readable by assistive technology.
