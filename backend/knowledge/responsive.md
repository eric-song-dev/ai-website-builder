# Responsive design system

Start with a compact single-column layout and enhance at wider widths. Use fluid type with clamp, flexible grids with minmax, and sensible content measures. Navigation, cards, tables, and calls to action must remain usable at 320 CSS pixels. Prefer CSS grid and flexbox over fixed positioning.

Keep touch targets at least 44 pixels, avoid horizontal page scrolling, and reserve image dimensions to prevent layout shift. Use semantic regions and a consistent spacing scale.
